# 从空项目一步步实现 Harness

第一次使用先跟着 [第 00 步新手引导](GETTING-STARTED.md) 做。阅读任务卡，编辑器写文件，终端运行，在自己的笔记中记录证据；所有入口在本机调试，Compose 只提供按需外部资源。

桌面分支：00～17 → 24～27 → 40～46，可在 Web 后直接进入。当前 src/ 与 tests/ 为空，也没有 desktop/ 成品。下面的文件和测试都要自己创建，已有文件则修改，不覆盖此前能力。

## 00 建立可断点的空项目

**开始前：**先确认前置 无；未满足时只预览，先补齐再验收。

**在本机编辑器：**新增或修改 `src/main.ts`、`tests/00-baseline.test.ts`

先按 [完整第 00 步操作](GETTING-STARTED.md) 创建最小 main.ts 和首个测试，再验证 dev、build、构建产物与调试。

**应该观察：**断点命中、退出码、构建产物与 source map。

**故障复现：**把运行入口指向不存在的文件，确认失败可以直接定位。

**断点：**程序入口、输入与退出位置

**怎样算完成：**新建实现项目并保留 demo、test、build 三个入口；实验室仅作对照。

**记录验收：**在自己的学习笔记中写下解释、实际产物与故障修正，确认完成条件后再进入下一步。
