主概念深挖：事件溯源与投影

Session 事件账本位于 Agent 等事实产生者的下游、持久化和所有读模型的上游，是恢复、观测和客户端同步的权威源。

Agent / LLM / Tool / Permission（写入命令结果）
                    │ append(event)
                    ▼
             Session Event Log
          ┌─────────┼──────────┐
          ▼         ▼          ▼
      Messages    Usage    Lifecycle / Surface（读投影）
          │         │          │
          └────► 模型、UI、成本、恢复（下游）
背景与目的只保存“当前状态”无法解释状态怎样形成，也难以修复崩溃；保存事实序列可重建任意读模型并保留审计链。
输入与输出输入是带类型的 Session 事件；输出是连续事件序列以及消息、用量、生命周期和模型可见面的派生视图。
适用场景长会话、冷恢复、断线续传、成本复算、上下文压缩和故障审计。
底层组件追加数组、连续序号、事件监听器、纯折叠函数、区间替换操作和生命周期状态机。
核心逻辑写侧只追加不可变事实；读侧从序号 0 依次折叠。最终用量覆盖流样本，Surface 替换只改变模型视图而不删除事实。
权衡事件日志占用更多存储且投影需要计算，但获得完整历史、确定重放和新增读模型无需改写旧数据。
方案对比状态快照读取快却缺少过程；事件日志信息完整但重放成本高；生产系统常以事件为真源、快照作加速缓存。

场景穷举

事件重放
├─ 连续且闭合 → 得到完整消息/用量/生命周期
├─ 重复事件 → 在网络客户端按 seq 去重
├─ seq 缺口 → 拒绝继续，重新取权威前缀
├─ open turn/step → 生命周期显示运行中或交给恢复修复
└─ surface replace → 只改变模型视图，原事件仍可审计
场景投影结果关键原因
正常一轮消息、最终用量和闭合生命周期一致。所有投影读取同一事件序列。
流式用量中间样本可展示，最终样本覆盖同一步骤。避免一个请求被重复计费。
空助手消息用量进入统计，消息不进入模型历史。传输可能只有 usage 而没有内容。
压缩替换模型看到摘要，审计仍看到原始消息。事实面和模型可见面职责不同。
损坏日志生命周期投影指出具体序号并失败。不猜测缺失事件的含义。

多方案对比

方案读取审计/恢复适用条件
只存当前状态最快。无法解释过程和重建旧视图。无历史要求的简单 CRUD。
事件日志实时重放历史越长越慢。最完整、最确定。本实验和中等长度会话。
事件日志+快照缓存从快照后增量重放。快照可删，事件仍是真源。大规模生产会话。

关键设计反问

为什么投影不能偷偷修复坏日志？
每个投影若各自猜测，会得到互相矛盾的状态；修复必须在统一恢复边界产生显式事件。
为什么 Surface 不是另一个可变消息数组？
可变数组无法说明哪些历史被何次压缩替换；事件化 replace 才能重放压缩链。
投影计算太慢怎么办？
增加带事件序号的缓存或快照，但缓存必须可删除并从权威日志重建，不能反客为主。

LLM stream ── usage chunk ─┐
final assistant/message ──┼──> append-only Session Event Log
tool call/result ─────────┘                 │
                           ┌────────────────┼───────────────┐
                           ▼                ▼               ▼
                    model history     token usage      lifecycle
                      projection       projection       projection
数据事实存放处投影规则
模型上下文user/assistant/tool-result 事件中的 Message忽略 chunk 和空 assistant message
Token usageassistant/chunk 或 assistant/message 的 usage同一 turn/step 后来的样本覆盖前者，防止重复计数
运行位置turn、step、tool 事件序列重放得到 open turn/step 和 pending tool calls
货币 cost本阶段没有独立权威字段由 TokenUsage × 模型价格派生时必须记录价格版本
投影不是备份。投影缓存丢失不会丢会话；事件日志丢失才会。恢复时先加载日志、验证 seq 连续，再重放投影。
