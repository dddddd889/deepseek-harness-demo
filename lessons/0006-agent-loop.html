第 6 课：Inbox 驱动的 Agent Loop

把用户输入、Session、LLM 串成一个不可重入的 turn/step 状态机，并让取消和错误也闭合日志。

状态与事件顺序

send() ──> Inbox
             │ run() 原子认领
             ▼
idle ──> running
          turn/start
          user/message × N
          step/start
          request/header
          assistant/chunk × N
          assistant/message（仅成功）
          step/end
          turn/end
             │
             ▼
            idle
FinishTurnEndReason本阶段含义
stopcompleted正常完成
max-tokensmax-tokens输出达到上限
errorerror保留结构化 failure
abortedaborted/user取消仍闭合 step/turn
tool-callsblocked等待下一课接入工具执行

必须验证的竞态

  1. 同一 Agent 并发 run() 必须拒绝，不能产生交错 seq。
  2. 运行期间新到的输入不能混进已认领 turn，必须留给下一 turn。
  3. 取消慢流后仍产生 step/end 与 turn/end。
  4. 恢复已有 Session 后，下一个 turn 编号不能从 1 重来。
