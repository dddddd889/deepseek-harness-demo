# 从空工程实现自己的 Harness

运行时、包管理和测试统一使用 **Bun 1.3.14**。当前唯一主线是 [70 步累计实操教程](linear/README.md)。从 [000](linear/lessons/000.md) 开始，只在一个空项目里逐步增加能力；每一步给代码、命令、断点、故障、验收、闭卷重做与迁移练习。

这套实现不导入原版产品代码。原版只在独立对照进程参与验收。完整目标仍在推进，尚缺行为和全部52组/342份包清单归属见 [范围核对](linear/COVERAGE.md)，实际证据见 [验证记录](linear/VERIFICATION.md)。

此前“把原版源码拆成代码册”的版本已退出主线并移到临时归档。旧24步原型与差距审计保留历史用途，不作为本教程的下一条路线，也不作为完整复刻证明。
