Agent需要在网页表单填入中文并点击提交，再看真实页面是否改变。浏览器DOM操作与操作系统屏幕点击是两个领域：网页里能定位button，不代表已经能控制其他应用窗口。

### 创建 `src/browser.mjs`

````javascript
import { chromium } from 'playwright-core'
import { Web } from './web-tools.mjs'

/** 浏览器使用独立临时profile，不接管用户已登录的个人浏览器。 */
export async function browser(scope, executablePath, { allowLocal = false } = {}) {
  const instance = await chromium.launch({ executablePath, headless: true })
  scope.own(() => instance.close())
  const context = await instance.newContext(), page = await context.newPage(), policy = new Web({ allowLocal })
  await context.route('**/*', async route => { try { await policy.check(route.request().url()); await route.continue() } catch { await route.abort() } })
  return { page,
    async navigate(url) { await policy.check(url); await page.goto(url); return { title: await page.title(), text: await page.locator('body').innerText() } },
    async click(selector) { await page.locator(selector).click(); return await page.locator('body').innerText() },
    async fill(selector, text) { await page.locator(selector).fill(text) },
    screenshot: () => page.screenshot({ type: 'png' }),
  }
}
````

### 创建 `src/computer.mjs`

````javascript
import { posix } from 'node:path'
import { execute } from './process.mjs'

/** 先把动作编译为固定OS提供方命令；不接受模型传任意osascript。 */
export function computerSpec(action, platform = process.platform) {
  if (action.kind === 'screenshot' && platform === 'darwin') {
    // 要求绝对输出路径，避免空路径或以短横线开头的内容被当成截屏选项。
    if (typeof action.path !== 'string' || !posix.isAbsolute(action.path) || action.path.includes('\0')) throw Error('截图路径必须是无空字符的绝对路径')
    return { command: '/usr/sbin/screencapture', args: ['-x', action.path] }
  }
  if (action.kind === 'click' && platform === 'linux') {
    if (![action.x, action.y].every(value => Number.isSafeInteger(value) && value >= 0)) throw Error('坐标不合法')
    return { command: 'xdotool', args: ['mousemove', String(action.x), String(action.y), 'click', '1'] }
  }
  if (action.kind === 'key' && platform === 'darwin' && ['Return', 'Escape', 'Tab'].includes(action.key)) {
    // macOS的固定键码；不把外部输入拼成任意AppleScript。
    const codes = { Return: 36, Escape: 53, Tab: 48 }
    return { command: '/usr/bin/osascript', args: ['-e', 'tell application "System Events" to key code ' + codes[action.key]] }
  }
  throw Error('此平台/动作尚无真实提供方')
}

/** 系统授权失败原样返回，不能声称已经点击或截屏。 */
export async function computer(action, signal = new AbortController().signal, { runner = execute, platform = process.platform } = {}) {
  // runner允许测试检查执行契约而不控制桌面；正常调用仍执行真实系统命令。
  signal.throwIfAborted()
  const result = await runner(computerSpec(action, platform), signal)
  if (result.code) throw Error('系统动作失败：' + result.output)
  return result
}
````

### 创建 `tests/059-browser.test.mjs`

````javascript
import { test } from 'bun:test'
import assert from 'node:assert/strict'
import { browser } from '../src/browser.mjs'
import { computer, computerSpec } from '../src/computer.mjs'
import { Scope } from '../src/scope.mjs'

test('真实隔离Chrome执行页面动作，截图为PNG；系统动作不接受任意脚本', async () => {
  const scope = new Scope(), executable = process.env.HARNESS_CHROME ?? (process.platform === 'darwin' ? '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' : process.platform === 'win32' ? 'C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe' : '/usr/bin/google-chrome')
  try {
    const app = await browser(scope, executable)
    await app.page.setContent(`<input id="name"><button onclick="document.body.dataset.done='yes'">go</button>`)
    await app.fill('#name', '中文')
    await app.click('button')
    assert.equal(await app.page.locator('#name').inputValue(), '中文')
    assert.equal(await app.page.locator('body').getAttribute('data-done'), 'yes')
    assert.equal((await app.screenshot()).subarray(1, 4).toString(), 'PNG')
    assert.throws(() => computerSpec({ kind: 'key', key: 'arbitrary script' }, 'darwin'), /尚无/)
  } finally { await scope.close() }
})


// 以下系统侧测试不需要桌面权限，不实际截屏或向前台窗口发送输入。
test('系统截图生成固定命令，空格路径保留为一个参数', () => {
  assert.deepEqual(computerSpec({ kind: 'screenshot', path: '/tmp/系统 截图.png' }, 'darwin'), {
    command: '/usr/sbin/screencapture', args: ['-x', '/tmp/系统 截图.png'],
  })
  for (const path of ['', '-i', 'relative.png', '/tmp/bad\0.png', undefined]) {
    assert.throws(() => computerSpec({ kind: 'screenshot', path }, 'darwin'), /截图路径/)
  }
})

test('macOS按键只编译允许的固定键码', () => {
  // 同时检查三个允许的按键，以及脚本注入和未知按键被拒绝。
  for (const [key, code] of [['Return', 36], ['Escape', 53], ['Tab', 48]]) {
    assert.deepEqual(computerSpec({ kind: 'key', key }, 'darwin'), {
      command: '/usr/bin/osascript', args: ['-e', 'tell application "System Events" to key code ' + code],
    })
  }
  for (const key of ['Space', 'Return; do shell script "anything"', '']) {
    assert.throws(() => computerSpec({ kind: 'key', key }, 'darwin'), /尚无/)
  }
})

test('Linux点击保留坐标参数，拒绝非法坐标', () => {
  assert.deepEqual(computerSpec({ kind: 'click', x: 0, y: 240 }, 'linux'), {
    command: 'xdotool', args: ['mousemove', '0', '240', 'click', '1'],
  })
  for (const value of [-1, 1.5, NaN, Infinity, '10', Number.MAX_SAFE_INTEGER + 1]) {
    assert.throws(() => computerSpec({ kind: 'click', x: value, y: 0 }, 'linux'), /坐标/)
    assert.throws(() => computerSpec({ kind: 'click', x: 0, y: value }, 'linux'), /坐标/)
  }
})

test('没有提供方的平台动作组合明确拒绝', () => {
  for (const [platform, action] of [
    ['win32', { kind: 'screenshot', path: '/tmp/test.png' }],
    ['darwin', { kind: 'click', x: 0, y: 0 }],
    ['linux', { kind: 'key', key: 'Return' }],
  ]) assert.throws(() => computerSpec(action, platform), /尚无/)
})

test('系统执行转交固定命令和取消信号，并返回执行结果', async () => {
  const controller = new AbortController(), expected = { code: 0, output: '', bytes: 0 }
  // 固定执行替身只检查参数，不启动系统程序。
  const runner = async (spec, signal) => {
    assert.equal(signal, controller.signal)
    assert.deepEqual(spec, { command: 'xdotool', args: ['mousemove', '12', '34', 'click', '1'] })
    return expected
  }
  assert.equal(await computer({ kind: 'click', x: 12, y: 34 }, controller.signal, { runner, platform: 'linux' }), expected)
})

test('系统命令非零退出和启动失败不能返回成功', async () => {
  const action = { kind: 'key', key: 'Return' }
  await assert.rejects(computer(action, undefined, {
    platform: 'darwin', runner: async () => ({ code: 1, output: '辅助功能权限不足' }),
  }), /系统动作失败：辅助功能权限不足/)
  // 命令缺失等底层错误保持原对象，便于调用方判断原因。
  const failure = Object.assign(Error('找不到命令'), { code: 'ENOENT' })
  await assert.rejects(computer(action, undefined, {
    platform: 'darwin', runner: async () => { throw failure },
  }), error => error === failure)
})

test('已取消或参数非法时不进入执行器', async () => {
  let calls = 0
  const runner = async () => { calls++; return { code: 0 } }
  const controller = new AbortController(); controller.abort()
  await assert.rejects(computer({ kind: 'click', x: 0, y: 0 }, controller.signal, { runner, platform: 'linux' }))
  await assert.rejects(computer({ kind: 'click', x: -1, y: 0 }, undefined, { runner, platform: 'linux' }), /坐标/)
  assert.equal(calls, 0)
})
````

## 系统动作怎么验收

| 系统 | 截图 | 点击 | 按键 |
| --- | --- | --- | --- |
| macOS | screencapture | 未实现 | osascript：Return、Escape、Tab |
| Linux | 未实现 | xdotool，依赖X11环境 | 未实现 |
| Windows | 未实现 | 未实现 | 未实现 |

osascript是macOS自带的AppleScript执行程序，`-e`后面是脚本；本章只把允许的按键映射成固定键码，不接受任意脚本。按键发送给当前焦点窗口，通常需要辅助功能权限。xdotool也不是通用Wayland提供方；没有对应实现的动作明确报错。

### 1. 默认自动测试：不控制你的桌面

执行 `bun test ./tests/059-browser.test.mjs`。其中1项启动隔离Chrome，另外7项验证系统命令参数与执行契约。测试传入platform，因此即使在macOS上，也能检查Linux的命令生成；这不等于实际运行了Linux命令。

computer的第三个参数允许注入runner与platform。普通调用默认使用真实execute；测试的runner只记录参数或返回错误，不截屏、不点击、不向窗口输入。

### 2. macOS真实截屏：单独执行

先创建本章的scripts/computer-smoke.mjs，然后在自己的PROJECT执行：

```sh
bun scripts/computer-smoke.mjs --screenshot
```

需要本机macOS图形会话，以及终端或宿主应用相应的屏幕录制权限。脚本实际调用computer、运行screencapture，检查生成文件的完整PNG签名，最后删除临时图片。桌面可能含私人内容，请先整理屏幕；脚本不上传图片。命令失败或文件无效会报错，不会skip后算通过。本轮没有执行真实截屏验收。

### 3. 真实点击与按键：仍未验收

当前没有为真实输入准备专用测试窗口，也没有验证Linux图形环境与系统权限。自动测试通过只证明固定命令与错误处理，不能证明目标窗口收到按键或点击。此处保留缺口，不提供会盲目操作日常窗口的自动测试。

### 平台支持要以本仓库固定版本为准

以下结论对应本教材固定原版基线687f282e8625c6b8d11ff58211a90524be2e4317，不代表上游未来版本。依据是[共享CUA文档的已知限制](../../../deepseek-harness/packages/experimental/cua/README.zh.md#known-limitations-and-deferred-work)、[macOS提供方](../../../deepseek-harness/packages/experimental/cua-macos/README.zh.md)及本仓库实现。

| 平台或入口 | 原版固定版本的支持情况 | 能得出的结论 |
| --- | --- | --- |
| macOS内置原生提供方 | 已有cua-macos包及Swift helper源码 | 有真实原生执行路径；本次没有重新进行桌面验收 |
| Windows内置原生提供方 | 文档计划独立提供方包与C# helper | 规划不能当作已实现或已验证 |
| Linux内置原生提供方 | 当前基线未发现相应提供方实现 | 不能由共享CUA接口推断Linux桌面已支持 |
| 外部Cua Driver MCP | 已有连接已安装驱动的适配包 | 具体系统能力由外部驱动及权限决定，不能据此承诺跨平台可用 |

浏览器自动化和桌面控制分别判断：浏览器提供方能工作，不等于能够控制该系统的其他应用窗口。教程里的Linux xdotool分支，也不是从原版Linux原生提供方移植来的。

### 原版macOS：共享工具层加原生辅助程序

```mermaid
sequenceDiagram
    participant A as 模型与工具执行链
    participant C as 共享CUA层
    participant P as macOS连接器
    participant N as Swift原生helper
    participant O as macOS系统API
    A->>C: 选择应用、读状态或发送动作
    C->>C: 校验参数、应用授权及截图坐标映射
    C->>P: 关联请求并通过本地连接发送JSON操作
    P->>N: Unix socket握手与操作请求
    N->>N: 校验目标身份、窗口与权限，按队列执行
    N->>O: AX观察、ScreenCaptureKit截图或CoreGraphics输入
    O-->>N: 系统观察结果或动作分派结果
    N-->>P: 返回对应请求结果
    P-->>C: 响应或错误
    C-->>A: 工具结果，截图进入图像接纳链
    A->>C: 再读新状态，确认动作实际效果
```

[macOS入口](../../../deepseek-harness/packages/experimental/cua-macos/src/index.ts)准备helper并调用installCua；[连接器](../../../deepseek-harness/packages/experimental/cua-macos/src/shared-native.ts)负责共享原生程序与本地socket连接；[NativeClient](../../../deepseek-harness/packages/experimental/cua/src/native-client.ts)负责请求关联、取消等通信约束。共享helper可被多个Agent或Host连接使用，每条连接分别保存句柄与快照，桌面操作通过全局队列执行。

| 原生职责 | 对应源码 | 做什么 |
| --- | --- | --- |
| 读取辅助功能状态 | [AXAccess.swift](../../../deepseek-harness/packages/experimental/cua-macos/native/Sources/CuaNative/AXAccess.swift) | 通过AX接口读取应用、窗口和元素 |
| 获取窗口截图 | [WindowCapture.swift](../../../deepseek-harness/packages/experimental/cua-macos/native/Sources/CuaNative/WindowCapture.swift) | 使用ScreenCaptureKit捕获窗口 |
| 发送键盘事件 | [KeyboardInput.swift](../../../deepseek-harness/packages/experimental/cua-macos/native/Sources/CuaNative/KeyboardInput.swift) | 构造CoreGraphics键盘事件，处理按下与释放 |
| 发送窗口指针事件 | [WindowPointerInput.swift](../../../deepseek-harness/packages/experimental/cua-macos/native/Sources/CuaNative/WindowPointerInput.swift) | 处理窗口内的鼠标输入 |

动作返回dispatched:true、verified:false，表示已分派而不是业务目标已成功。比如“点击提交”仍需要重新读取窗口状态，确认出现了提交结果。

### 与教程简化实现的区别

```mermaid
flowchart TD
    subgraph O[原版macOS]
        O1[Agent工具与共享CUA层] --> O2[授权、句柄、快照与坐标校验]
        O2 --> O3[本地socket连接]
        O3 --> O4[Swift helper与原生系统API]
    end
    subgraph T[本节简化实现]
        T1[独立computer函数，尚未注册为Agent工具] --> T2[computerSpec生成白名单命令]
        T2 --> T3[execute启动外部程序]
        T3 --> T4[macOS的screencapture或osascript]
        T3 --> T5[Linux X11的xdotool]
    end
```

| 方面 | 原版macOS | 本节简化实现 |
| --- | --- | --- |
| 调用入口 | 已挂载共享CUA工具链 | 独立辅助函数，未接Agent工具表 |
| 执行方式 | Swift程序调用原生API | 启动系统命令行程序 |
| 目标定位 | 应用句柄、窗口、AX快照和截图坐标 | 截图路径、屏幕坐标或有限按键 |
| 授权与状态 | 应用授权、系统权限、快照有效性等分层检查 | 命令白名单和参数检查，依赖系统权限，失败抛错 |
| 测试证据 | 原版有自身测试，本节没有重新执行原版桌面验证 | 1项真实浏览器测试、7项系统侧自动测试；真实系统截屏另行验收 |

本节的价值是先理解“页面动作”和“系统动作”具有不同执行边界；它不等于复刻了原版CUA提供方。外部[MCP适配包](../../../deepseek-harness/packages/experimental/computer-use-cua-driver-mcp/README.zh.md)是另一种接入路径：驱动自行承担桌面能力，Harness通过MCP发现和调用其工具。
