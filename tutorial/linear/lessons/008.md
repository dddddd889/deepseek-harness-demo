# 008 · 一份日志生成模型历史、fork 和冷搜索

## 什么时候会用到这一页

模型输出“正在想”时，界面可先显示分片，但下一次模型请求只应包含提交好的用户、assistant与工具消息。用户从“修复取消”的消息分叉新会话时，父历史保持不变；搜索历史不应顺便创建Agent或调用模型。

### 这次数据怎么走

```text
Events.read → messages只挑message/user、message/assistant、message/tool → 模型历史；fork(parent,child,through)先写lineage再复制切点之前的message事件；search遍历已给定Session的事件数据 → 返回sessionId与seq。
```

**当前接线位置：**messages在012/014/016的Loop生成请求历史时真实使用；fork与search只在008单测直接调用。041 Host虽导入messages但该文件没有调用，不能把一个import当成分叉或搜索已接线；066另有SessionQuery实现，与008的内存search不是同一条调用链。

### 创建 `src/projection.mjs`

````javascript
/** 只投影已提交内容；流式分片是显示状态，不自行进入模型历史。 */
export function messages(events) {
  return events.filter(event => ['message/user', 'message/assistant', 'message/tool'].includes(event.type))
    .map(event => structuredClone(event.data))
}

/** Fork 保留完整事实前缀与 lineage，不修改父历史。 */
export function fork(parent, child, through) {
  if (!Number.isSafeInteger(through) || through < -1 || through >= parent.records.length) throw Error('fork 位置不合法')
  child.append('lineage', { parent: parent.id, through })
  for (const event of parent.read().filter(event => event.seq <= through)) {
    if (event.type.startsWith('message/')) child.append(event.type, event.data)
  }
  return child
}

/** 查询只读日志，不创建 Agent，不产生模型调用。 */
export function search(sessions, query) {
  return sessions.flatMap(session => session.read().filter(event => JSON.stringify(event.data).includes(query))
    .map(event => ({ sessionId: session.id, seq: event.seq, data: event.data })))
}
````

### 创建 `tests/008-projection.test.mjs`

````javascript
import { test } from 'bun:test'
import assert from 'node:assert/strict'
import { Events } from '../src/events.mjs'
import { messages, fork, search } from '../src/projection.mjs'

test('分片不混进模型历史，fork 不改父会话，搜索是冷读', () => {
  const parent = new Events('p'), child = new Events('c')
  parent.append('message/user', { role: 'user', content: '修复取消' })
  parent.append('stream/text', { text: '暂时' })
  fork(parent, child, 1)
  assert.equal(messages(child.read()).length, 1)
  assert.equal(parent.read().length, 2)
  assert.equal(search([parent], '取消')[0].seq, 0)
})
````
