DeepSeek Harness：17 个可调试阶段

目标不是一次复制整个 monorepo，而是按依赖顺序构建 17 个始终可运行的垂直切片。

每阶段统一完成定义：有一个可执行入口、一个最小自动测试、一组断点位置、一份可检查状态产物；上一阶段保持通过后才能进入下一阶段。

固定调试协议

  1. 单元层：每个状态机或 fold 使用 bun:test 固定输入和精确输出。
  2. 协议层：所有跨边界对象可 JSON 序列化，并保存 fixture。
  3. 运行层：在 VS Code Run and Debug 中选择阶段配置并按 F5。
  4. 事件层：每个 Turn 输出连续 seq 的事件日志，禁止仅靠 console 文本猜测。
  5. 故障层：至少覆盖取消、超时、进程中断和重复请求。
  6. 回归层：每阶段保留 smoke test，最终形成 1→17 的累积测试梯。
